# 🍳 Kora — Smart Kitchen Assistant

Kora is a modern smart kitchen management Android application built using **Kotlin** and **Jetpack Compose**.  
It acts as an intelligent kitchen assistant that helps users:

- Manage food inventory
- Track expiring items
- Monitor smart appliances
- Get recipe suggestions
- Interact with AI-powered kitchen assistance

---

# ✨ Features

## 🏠 Smart Dashboard
- AI assistant interface
- Animated Kora orb

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/akashkanabur/ChatBot.git
```

## Open Project
- Open Android Studio
- Select project folder
- Sync Gradle

## Run Application
- Connect Android device OR start emulator
- Click ▶ Run

```bash
Build → Generate APK(s)
```
